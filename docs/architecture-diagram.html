How the edit pipeline actually works

The document never gets rewritten wholesale. The model proposes a short list of paragraph-level edits; plain code — not the model — decides which ones are trustworthy enough to apply.

1. The pipeline, end to end

One LLM call turns the document and the change list into a set of edit instructions. Everything after that — accepting, rejecting, applying, double-checking — is deterministic code with no model involved.
